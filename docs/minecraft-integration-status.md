# Интеграция Minecraft

## Forge Bridge

Двусторонняя интеграция реализована через отдельные Forge Bridge JAR:

- Minecraft 1.12.2 / Java 8;
- Minecraft 1.16.5 / Java 8;
- Minecraft 1.18.2 / Java 17;
- Minecraft 1.19.2 / Java 17;
- Minecraft 1.20.1 / Java 17.

Bridge устанавливается только на сервер или компьютер владельца мира «Открыть для сети». Клиенты подключаются без него. Протокол рассчитан на независимое развитие UI RadminCraft без постоянной пересборки модов.

Работают игровой чат в обе стороны, вход/выход, координаты, heartbeat, одноразовая привязка профиля и защита от повторной доставки.

## Привязка профиля

Код появляется только когда Host настроил Bridge. Пользователь получает одноразовый код в профиле и отправляет `!radmincraft link КОД` обычным сообщением игрового чата. Код действует пять минут; старый код после отмены или истечения срока не принимается.

## BlueMap

BlueMap независим от Bridge и нужен только для веб-карты. Host выбирает версию по точному совпадению Minecraft, Forge и Java на официальной странице выпусков. Игрокам BlueMap не нужен.
