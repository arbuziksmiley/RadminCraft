# Дополнение к ТЗ: Minecraft-стикеры в общем чате

> **Актуальное решение (обновлено):** стикеры **статичные**, не анимированные. Реализованный пакет — 50 статичных PNG (`src/assets/stickers/static/mc-00.png … mc-49.png`). Формулировки про «анимированные» ниже устарели и оставлены как исторический контекст.

## Назначение

RadminCraft поддерживает один встроенный пакет из 50 статичных Minecraft-тематических стикеров. Стикеры помогают выражать реакцию в общем текстовом чате, как в мессенджерах.

## Поведение

- В поле ввода общего чата есть кнопка открытия панели стикеров.
- Панель показывает только встроенный пакет; добавление пользовательских пакетов, файлов и внешних ссылок в первой версии не поддерживается.
- Стикер отправляется отдельным сообщением с идентификатором пакета и стикера, а не как произвольный файл.
- Клиент кэширует встроенные ресурсы локально; Host хранит только идентификатор сообщения и стикера.
- Стикер можно удалить по тем же правилам, что и текстовое сообщение: автор удаляет своё, владелец Host — любое.
- История чата хранит ссылку на стикер в течение тех же 30 дней.

## Связь с Minecraft

- Стикеры отображаются только в RadminCraft.
- Forge Bridge не передаёт GIF/стикеры в обычный Minecraft-чат, поскольку он не поддерживает анимированные изображения.
- При отправке стикера из RadminCraft Bridge передаёт в игровой чат нейтральное текстовое событие `[RC: стикер]` от имени привязанного игрока. Изображение при этом остаётся только в RadminCraft.

## Ресурсы и безопасность

- В пакет входят ровно 50 лицензированных или созданных специально для RadminCraft анимаций в GIF или WebP.
- Размер одного ресурса ограничивается 512 КБ, сторона — 256 px, длительность — 3 секунды.
- Встроенный пакет поставляется с приложением; клиент не загружает GIF по произвольным URL.
- Перед добавлением сторонних работ требуется проверка лицензии на распространение внутри приложения.
