# Закрытие RadminCraft Host

Если пользователь выбрал режим Host, приложение предупреждает при попытке закрыть окно: закрытие остановит Host, поэтому участники потеряют доступ к общему чату, голосовому каналу, карте и Forge Bridge.

В диалоге есть безопасное действие по умолчанию «Оставить Host запущенным» и явное подтверждение «Всё равно закрыть». Для обычного Client это предупреждение не показывается.
