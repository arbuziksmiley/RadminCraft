# Распространение RadminCraft

## Поддерживаемая платформа

- Windows 10 x64;
- Windows 11 x64.

Другие ОС и 32-битная Windows в первом публичном выпуске не поддерживаются.

## Установщик

RadminCraft распространяется одним NSIS-файлом `RadminCraft-Setup-X.Y.Z.exe`.
Он устанавливается для текущего пользователя, позволяет выбрать каталог,
создаёт ярлыки рабочего стола и меню «Пуск» и регистрирует удаление приложения.

Установщик, `latest.yml` и `.blockmap` прикрепляются к GitHub Release. Они не
коммитятся в основную ветку.

## Обновления

`electron-updater` получает только опубликованные стабильные релизы из
`arbuziksmiley/RadminCraft`. Приложение не скачивает и не выполняет код прямо
из ветки `main`.

Скачивание начинается после подтверждения пользователя. Отказ откладывает
напоминание на 48 часов. После загрузки пользователь подтверждает перезапуск.
Данные `%APPDATA%\radmincraft` при обновлении сохраняются.

## Целостность и доверие

- GitHub раздаёт Release assets по HTTPS;
- electron-updater проверяет метаданные и blockmap electron-builder;
- SHA-256 установщика публикуется в описании релиза;
- исходники и автоматическая сборка доступны в том же репозитории;
- до приобретения Code Signing Windows SmartScreen может предупреждать о
  неизвестном издателе.

## Восстановление

Перед beta-обновлением рекомендуется копировать `%APPDATA%\radmincraft`.
При проблеме пользователь может установить предыдущий EXE из GitHub Releases
поверх текущей версии; формат настроек нельзя ломать без миграции.
