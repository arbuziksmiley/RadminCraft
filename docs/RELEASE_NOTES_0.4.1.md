# RadminCraft 0.4.1 beta

Первый публичный beta-релиз RadminCraft для Windows 10/11 x64.

## Основное

- общий чат, ответы, поиск, упоминания, `@all`, смайлы и 50 стикеров;
- непрочитанные упоминания с переходом к сообщению;
- голосовой канал WebRTC и выбор аудиоустройств;
- 150 уникальных Minecraft-аватаров;
- Radmin VPN Host/client и диагностика подключения;
- карта BlueMap;
- временный Host для чата, presence и сигнализации голоса;
- двусторонний Forge Bridge для Minecraft 1.12.2, 1.16.5, 1.18.2, 1.19.2 и 1.20.1;
- автоматическая проверка следующих версий через GitHub Releases.

## Установка

Скачайте `RadminCraft-Setup-0.4.1.exe`. Установщик пока не подписан коммерческим
сертификатом, поэтому Windows SmartScreen может показать предупреждение.

SHA-256 опубликован рядом с установщиком в файле `SHA256SUMS.txt`.

## Известные ограничения

- это beta: перед обновлением сохраните `%APPDATA%\radmincraft`;
- временный Host не переносит Minecraft-сервер и BlueMap;
- для сети и голоса нужен Radmin VPN и проверка на реальных компьютерах;
- Bridge ставится только владельцу сервера/мира LAN, обычным игрокам не нужен.
