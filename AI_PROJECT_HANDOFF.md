# RadminCraft — контекст для продолжения разработки

Прочитать полностью перед изменениями. Этот файл поддерживается как короткая точка входа для нового сеанса Codex; подробности находятся в исходниках, тестах и `docs/`.

## Цель и границы

RadminCraft — Electron-приложение для Windows 10/11 x64. Оно объединяет небольшой Minecraft-клуб в одной сети Radmin VPN: чат, голос, presence, карту, ссылку на моды, запуск лаунчера и уведомления. Белый IP не требуется.

Один экземпляр приложения на компьютере работает с одним сообществом. Основной Host слушает TCP `18483` на Radmin-адресе `26.*`. Клиенты используют тот же установщик, но другую роль.

Владелец GitHub: `arbuziksmiley`. Планируемый репозиторий: `RadminCraft`.

## Архитектура

- `electron/main.js` — жизненный цикл, локальное хранение, Host HTTP API, Radmin VPN, WebRTC-сигнализация, presence, карта, Bridge, диагностика и временный Host.
- `electron/preload.js` — единственный безопасный IPC-мост renderer → main.
- `electron/protocol.js` — чистая нормализация сетевого протокола.
- `electron/failover.js` — подписи, ранжирование кандидатов и слияние состояния временного Host.
- `electron/updater.js` — GitHub Releases / electron-updater.
- `src/renderer.js` — основное состояние интерфейса и чат.
- остальные `src/*.js` и `src/*.css` — изолированные функции и исправления экранов.
- `forge-bridge/common` — независимое от Minecraft ядро Bridge.
- `forge-bridge/forge-*` — тонкие адаптеры конкретных версий Forge.
- `forge-bridge/dist` — пять готовых JAR, включаемых в установщик.
- `tests` — чистая логика протокола, failover и разбора Minecraft.

Пользовательские данные находятся вне проекта в `%APPDATA%\radmincraft`.

## Реализовано

- onboarding Host/клиент, профиль и 150 аватаров;
- чат, поиск, ответы, удаления, упоминания и непрочитанные;
- голос WebRTC, устройства, громкость участника, приглашения, автоотключение одиночки;
- presence с защитой от кратких сетевых провалов;
- Radmin VPN и портовая диагностика;
- ссылка на моды и локальный лаунчер;
- BlueMap iframe, выгрузка, повторное подключение, fullscreen;
- Forge Bridge и двусторонний Minecraft-чат;
- привязка Minecraft-профиля одноразовым кодом;
- временный Host для чата/presence/signaling;
- GitHub auto-update с ручным скачиванием;
- установщик NSIS, ярлыки, автозапуск, трей, собственные уведомления и логи инцидентов.

## Важные ограничения

- не заявлять полную стабильность, пока сеть и голос не проверены на нескольких реальных ПК;
- временный Host не переносит Minecraft, BlueMap или Forge Bridge;
- Bridge ставится только владельцу сервера/мира LAN, клиентам не требуется;
- BlueMap выбирается по точному сочетанию Minecraft + Forge + Java;
- автообновление работает только из установленной сборки и только по опубликованному (не draft) GitHub Release;
- первый установщик unsigned и вызывает SmartScreen;
- лицензию владелец ещё не выбрал.

## Проверки после любого изменения

```powershell
npm ci
npm run check
npm test
npm run dist
```

Для сетевого релиза дополнительно вручную проверить:

1. Host и клиент на двух компьютерах одной Radmin VPN сети;
2. переподключение после краткой потери сети;
3. вход/выход и звук голосового канала;
4. временный Host и возврат основного;
5. Bridge на отдельном сервере и в мире «Открыть для сети»;
6. BlueMap по адресу Host;
7. обновление с предыдущего опубликованного релиза.

## Правила продолжения

- сначала читать `AGENTS.md`, этот файл и релевантный документ из `docs/`;
- не переписывать рабочие подсистемы без доказанной причины;
- не выдавать UI-заглушку за готовую функцию;
- сохранять совместимость настроек или добавлять миграцию;
- не включать в Git `node_modules`, `release`, `tmp`, Gradle-кэши и пользовательские данные;
- не удалять `forge-bridge/dist`: эти JAR включаются в установщик;
- при изменении Bridge сохранять обратную совместимость протокола либо повышать `BRIDGE_PROTOCOL`.
