# RadminCraft

RadminCraft — Windows-приложение для небольшой компании игроков Minecraft в одной сети Radmin VPN. Один компьютер запускает RadminCraft в роли **Host**, остальные подключаются как обычные участники. Пока многие в России ломают голову над тем, какими актуальными способами можно обойти блокировки для Discord, Telegram и других мессенджеров, я создал простую программу, которая будет выступать в роли небольшого и ни от кого не зависящего частного решения для вас и ваших друзей.

Целевая платформа: **Windows 10 и Windows 11, x64**.

> Версия `0.4.0` — первый публичный beta-релиз. Перед использованием на важном сообществе сохраните резервную копию `%APPDATA%\radmincraft`.

## Что умеет приложение

- общий чат с историей, поиском, ответами, `@упоминаниями`, `@all`, смайлами и статичными стикерами;
- непрочитанные упоминания с переходом к нужному сообщению;
- общий голосовой канал WebRTC, выбор устройств и громкости участников;
- профили с 150 встроенными Minecraft-головами и локальными псевдонимами друзей;
- статусы «в сети», «в лаунчере» и «в игре»;
- запуск выбранного Minecraft-лаунчера;
- ссылка Host на актуальную сборку модов;
- встроенная веб-карта BlueMap с выгрузкой из памяти и полноэкранным режимом;
- уведомления поверх окон и отдельные настройки звуков;
- автозапуск вместе с Windows;
- диагностика Radmin VPN, Host и порта `18483`;
- временный Host для чата, presence и сигнализации голоса при пропадании основного Host;
- двусторонний мост Minecraft ↔ RadminCraft через необязательный Forge Bridge;
- проверка новых версий через GitHub Releases.

## Установка

1. Установите и настройте Radmin VPN на всех компьютерах.
2. Скачайте `RadminCraft-Setup-0.4.0.exe` из раздела **Releases** этого репозитория.
3. Запустите установщик и выберите папку.
4. На компьютере владельца выберите роль **Host**, на остальных — **Обычный игрок**.
5. Участникам понадобится адрес Host вида `26.x.x.x:18483`.

Установщик пока не подписан коммерческим сертификатом. Windows SmartScreen может показать предупреждение. Проверяйте, что файл скачан именно из `github.com/arbuziksmiley/RadminCraft/releases`, и сверяйте SHA-256 из примечаний к релизу.

Профиль, настройки и история хранятся в `%APPDATA%\radmincraft`. Обновление и обычное удаление приложения их не стирают.

## Обновления

Установленная версия проверяет публичные GitHub Releases при запуске и раз в 48 часов. Если доступна более новая стабильная версия:

1. в колокольчике появится уведомление;
2. пользователь сам решает, скачать её или напомнить через два дня;
3. после загрузки приложение предлагает перезапуск;
4. установщик заменяет программу, сохраняя данные в `%APPDATA%\radmincraft`.

Для работы автообновления у релиза должны быть опубликованы **все три** файла, созданные electron-builder: `.exe`, `.exe.blockmap` и `latest.yml`. Черновики GitHub Release клиент не видит.

## Forge Bridge

Bridge ставится только на компьютер, где работает сервер Minecraft или мир «Открыть для сети». Подключающимся игрокам он не нужен.

| Minecraft | Forge | Java |
|---|---|---|
| 1.12.2 | 14.23.5.2860 | 8 |
| 1.16.5 | 36.2.42 | 8 |
| 1.18.2 | 40.2.31 | 17 |
| 1.19.2 | 43.4.0 | 17 |
| 1.20.1 | 47.4.17 | 17 |

Готовые JAR находятся в `forge-bridge/dist`. Host выбирает свою версию в мастере интеграции, после чего RadminCraft копирует подходящий JAR в папку `mods`.

Bridge передаёт чат в обе стороны, вход/выход игроков, координаты и подтверждение привязки профиля. Если RadminCraft выключен, Minecraft продолжает работать. Подробнее: [forge-bridge/README.md](forge-bridge/README.md).

## BlueMap

BlueMap устанавливает только Host. Игрокам мод BlueMap не требуется.

Нельзя советовать один JAR для всех сборок: на странице выпуска проверяйте таблицу **Targets** и выбирайте файл, где совпадают:

- версия Minecraft;
- загрузчик **Forge**;
- требуемая версия Java.

Официальные файлы: [BlueMap Releases](https://github.com/BlueMap-Minecraft/BlueMap/releases). Эта ссылка также доступна в мастере интеграции RadminCraft. Стандартный веб-порт — `8100`.

Если блоки на карте появляются не сразу, проверьте команды `/bluemap tasks`, `/bluemap update` и параметр `update-cooldown` в `config/bluemap/core.conf`.

## Ограничения beta

- связь рассчитана на одну выбранную сеть/сообщество RadminCraft за один запуск;
- временный Host не переносит сам Minecraft-сервер, BlueMap и серверные инструменты;
- при полном разделении Radmin VPN две изолированные группы не могут безопасно определить, кто видит основной Host;
- голос и сетевые сценарии требуют проверки минимум на двух реальных компьютерах;
- установщик пока без цифровой подписи;
- приложение и Bridge не проходили независимый аудит безопасности.

## Разработка

Нужны Node.js 22+, npm и Windows 10/11 x64.

```powershell
npm ci
npm run check
npm test
npm start
```

Сборка установщика:

```powershell
npm run dist
```

Результат появится в `release/`. Кэши и старые сборки удаляются командой:

```powershell
npm run clean
```

Следующему разработчику или сеансу Codex сначала нужно прочитать [AGENTS.md](AGENTS.md) и [AI_PROJECT_HANDOFF.md](AI_PROJECT_HANDOFF.md).
