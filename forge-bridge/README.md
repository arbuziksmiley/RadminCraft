# RadminCraft Forge Bridge

Серверный необязательный мод, связывающий Minecraft с локальным RadminCraft
Host. Игрокам устанавливать его не требуется.

## Выпуски

Каждая версия Minecraft получает отдельный JAR, но использует одно ядро:

| Minecraft | Forge | Java |
|---|---|---|
| 1.12.2 | 14.23.5.2860 | 8 |
| 1.16.5 | 36.2.42 | 8 |
| 1.18.2 | 40.2.31 | 17 |
| 1.19.2 | 43.4.0 | 17 |
| 1.20.1 | 47.4.17 | 17 |

`common/` не зависит от API Minecraft. Каталоги `forge-*` содержат только
обработчики событий конкретной версии. CI и локальный `build-all.ps1` собирают
отдельные JAR.

## Принципы

- никакого сетевого I/O в server tick thread;
- bounded queue и exponential backoff;
- повторная доставка безопасна благодаря event/command ID;
- неизвестные команды и поля игнорируются;
- мод не добавляет контент и не обязателен клиентам;
- HTTP доступен только через `127.0.0.1:18483`;
- если RadminCraft выключен, Minecraft продолжает работать без ошибок.

Протокол: [`../docs/forge-bridge-http-protocol.md`](../docs/forge-bridge-http-protocol.md).

## Установка

Нужен ровно один JAR, соответствующий версии Minecraft:

- отдельный сервер: положить JAR в папку `mods` сервера;
- мир «Открыть для сети»: положить JAR в папку `mods` владельца мира;
- подключающимся игрокам мод не нужен;
- случайно установленный у игрока Bridge не мешает подключению к серверу без Bridge.

Готовые файлы после сборки находятся в `dist/`. Нельзя ставить JAR от другой версии
Minecraft: Forge справедливо отклонит несовместимый мод.

## Что работает

- чат Minecraft → RadminCraft, включая UTF-8 и русский текст;
- команда `!radmincraft link КОД` в игровом чате;
- чат RadminCraft → Minecraft;
- вход, выход, координаты и измерение игроков;
- автоматическое восстановление связи после перезапуска RadminCraft;
- безопасная повторная доставка без повторного исполнения уже подтверждённых команд.

Bridge общается только с RadminCraft на том же компьютере через `127.0.0.1:18483`.
