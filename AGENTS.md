# База полезных ресурсов и правила работы ИИ

Этот файл нужно класть в корень каждого нового проекта. Он одновременно является инструкцией для ИИ-агента и автономной базой ресурсов. Для его работы не нужна исходная папка со скриншотами.

## Обязательное правило

Перед планированием, выбором технологий, дизайном или реализацией существенной функции:

1. Сначала изучи задачу, код и ограничения текущего проекта.
2. Просмотри каталог ресурсов ниже и выбери только действительно подходящие позиции.
3. Перед подключением внешнего проекта проверь его актуальную документацию, лицензию, поддержку, безопасность и совместимость с текущим стеком.
4. Не устанавливай зависимости только потому, что они перечислены здесь. Предпочитай самое маленькое и надёжное решение.
5. Для UI используй ресурсы как источник компонентов, паттернов и вдохновения, но адаптируй результат под проект и не копируй чужой дизайн пиксель в пиксель.
6. В финальном ответе кратко назови ресурсы из этого файла, которые реально повлияли на результат. Если ничего не подошло, так и скажи.

Прямые инструкции пользователя и требования текущего проекта всегда важнее этого файла. Сведения ниже являются сохранённым снимком и со временем могут устареть — проверяй первоисточники перед использованием.

## ИИ-агенты, память и контекст

### Agent Skills

- Источник: <https://github.com/addyosmani/agent-skills>
- Набор готовых инструкций для ИИ-агентов, охватывающих цикл разработки: спецификация, планирование, реализация, тестирование, ревью, упрощение и выпуск.
- Использовать, когда агенту нужны структурированные процессы, чек-листы и критерии готовности.

### Headroom

- Источник: <https://github.com/chopratejas/headroom>
- Слой оптимизации и сжатия контекста для LLM-приложений и ИИ-агентов. Заявленная цель — уменьшение расхода токенов без существенной потери качества.
- Рассматривать для длинных агентных сессий и приложений с большим входным контекстом; перед интеграцией обязательно проверить качество сжатия на данных проекта.

### Mem0

- Источник: <https://github.com/mem0ai/mem0>
- Библиотека долгосрочной памяти для ИИ-агентов и ассистентов: сохраняет контекст между сессиями и предоставляет семантический поиск. Предназначена для работы с разными LLM-провайдерами.
- Подходит для персонализации, истории взаимодействий и долговременной памяти. Заранее определить политику хранения, удаления и защиты персональных данных.

### Codebase Memory MCP

- Источник: <https://github.com/DeusData/codebase-memory-mcp>
- Локальный MCP-сервер, строящий граф знаний по кодовой базе: функции, классы, файлы и связи между ними. На карточке указана поддержка большого числа языков.
- Использовать для навигации по крупным репозиториям и улучшения понимания кода агентом. Не применять вместо обычного поиска в небольших проектах.

### LMCache

- Источник: <https://github.com/LMCache/LMCache>
- Слой управления KV-кэшем для масштабируемого LLM-инференса. Переиспользует ранее обработанный контекст между запросами для снижения задержки и экономии GPU-ресурсов.
- Актуален только для собственной инфраструктуры инференса и повторяющихся длинных контекстов; требует измерения реального выигрыша.

### LiteRT-LM

- Источник: <https://github.com/google-ai-edge/LiteRT-LM>
- Движок Google AI Edge для запуска LLM непосредственно на Android, iOS, Windows, Linux, macOS, Web и IoT. В карточке отмечены ускорение на GPU/NPU, мультимодальность, tool calling и поддержка нескольких семейств моделей.
- Рассматривать для офлайн-режима, приватного локального инференса и приложений без постоянного облачного соединения.

## Интеграции, данные и автоматизация

### Nango

- Источник: <https://github.com/NangoHQ/nango>
- Платформа интеграций продукта или ИИ-агента с большим числом внешних API. Берёт на себя OAuth, хранение и обновление токенов, повторные попытки, синхронизацию и масштабирование; логика интеграции пишется на TypeScript.
- Использовать, когда проекту требуется много OAuth-интеграций. Для одного простого API сначала сравнить со своей небольшой реализацией.

### Public APIs

- Источник: <https://github.com/public-apis/public-apis>
- Каталог публичных API по категориям: погода, финансы, карты, переводы, изображения, новости, животные, аниме и другие.
- Использовать для поиска источника данных или быстрого прототипа. Отдельно проверять условия использования, лимиты, CORS, доступность и качество каждого API.

### DBeaver

- Источник: <https://github.com/dbeaver/dbeaver>
- Кроссплатформенный SQL-клиент и графический инструмент администрирования баз данных с поддержкой множества СУБД, редактором запросов и просмотром схем.
- Полезен для ручной диагностики, исследования структуры БД, миграций и проверки данных.

### Crawl4AI

- Источник: <https://github.com/unclecode/crawl4ai>
- LLM-ориентированный веб-краулер и скрейпер, преобразующий сайты в чистый Markdown для LLM и RAG. В карточке отмечены JavaScript, сессии, прокси и адаптивный обход.
- Использовать для разрешённого сбора данных и подготовки корпусов. Соблюдать robots.txt, условия сайтов, авторские права, лимиты запросов и требования к персональным данным.

### OfficeCLI

- Источник: <https://github.com/iOfficeAI/OfficeCLI>
- CLI/ИИ-инструмент для чтения, создания, редактирования и автоматизации Word, Excel и PowerPoint без обязательного Microsoft Office или облака.
- Рассматривать для локальной автоматизации офисных документов. Перед применением проверить поддержку нужных форматов и сохранность сложного оформления.

### Archify

- Источник: <https://github.com/tt-ali/archify>
- Создаёт архитектурные диаграммы по описанию или исходному коду и экспортирует их в SVG, PNG и другие форматы.
- Использовать для первичной документации архитектуры; результат обязательно сверять с реальным кодом и вручную уточнять.

## Веб-разработка, сборка и сети

### SWC

- Источник: <https://github.com/swc-project/swc>
- Быстрый компилятор JavaScript и TypeScript на Rust, применяемый современными веб-инструментами и фреймворками как альтернатива Babel для компиляции и сборки.
- Использовать через поддержку выбранного фреймворка или сборщика. Не добавлять отдельную конфигурацию без измеримой причины.

### Iroh

- Источник: <https://github.com/n0-computer/iroh>
- Rust-библиотека для прямого P2P-соединения устройств по постоянным ключам, с обнаружением пути и прохождением NAT. Упоминаются синхронизация между устройствами и P2P-приложения.
- Рассматривать для local-first, peer-to-peer и мультиустройственных приложений. Заранее продумать идентификацию, шифрование, офлайн-конфликты и резервный транспорт.

## Дизайн и готовые UI-компоненты

### UI Watermelon

- Сайт: <https://ui.watermelon.sh>
- Каталог готовых React-компонентов, блоков и дашбордов для копирования и адаптации: карточки, списки, слайдеры, формы раскрытия и другие элементы.
- Использовать как источник отдельных UI-паттернов, предварительно проверяя доступность, адаптивность и зависимости.

### AISDK Agents

- Сайт: <https://aisdkagents.com>
- Готовые UI-компоненты и примеры кода для чат-ботов и ИИ-агентов; на карточке показан компонент загрузки/показа изображения OpenAI.
- Полезен при создании чатов, интерфейсов генерации, состояний выполнения и визуализации agentic-процессов.

### Skiper UI

- Сайт: <https://skiper-ui.com>
- Коллекция готовых анимированных компонентов для shadcn/ui, устанавливаемых или копируемых по отдельности. В примерах: image reveal, hover members и другие интерактивные блоки.
- Использовать точечно. Учитывать производительность, prefers-reduced-motion, клавиатурную навигацию и мобильные устройства.

### Refero Styles

- Сайт: <https://styles.refero.design>
- Каталог из большого числа готовых дизайн-систем и визуальных направлений сайтов, пригодных как референсы или как описание стиля для ИИ-агента.
- Использовать для выбора визуального языка проекта: типографики, плотности, цветовой системы, карточек, сетки и общего настроения.

### Awesome Design Tools

- Источник: <https://github.com/goabstract/Awesome-Design-Tools>
- Большой каталог инструментов для дизайнеров: шрифты, градиенты, UI-киты, дизайн-системы, прототипирование, плагины, конференции и AR. Ресурсы помечаются как платные, бесплатные, open source или платформенные.
- Использовать как навигатор при поиске специализированного дизайн-инструмента, а не подключать весь список.

## Музыка и медиа

### Music Assistant

- Название из карточки: Music Assistant.
- Домашний сервер/приложение для управления музыкальной библиотекой, провайдерами, плеерами и воспроизведением из единого интерфейса.
- Рассматривать для self-hosted музыкальных проектов, домашних медиасистем и интеграции нескольких музыкальных источников. Перед использованием найти и проверить официальный актуальный репозиторий проекта.

### Spotube

- Источник: <https://github.com/KRTirtho/spotube>
- Кроссплатформенный музыкальный клиент для Android, iOS, Windows, macOS и Linux без рекламы и обязательной подписки. Использует метаданные Spotify, а аудио получает из YouTube и других источников через плагины.
- Может служить референсом архитектуры медиаплеера и кроссплатформенного UI. Перед применением учитывать правила музыкальных сервисов и правовые ограничения источников.

### IPTV

- Источник: <https://github.com/iptv-org/iptv>
- Большая база публичных IPTV-плейлистов и каналов, распределённых по странам, языкам и категориям и обновляемых сообществом.
- Использовать только для легально доступных потоков. Проверять права на вещание, доступность в регионе и стабильность конкретных источников.

## Быстрый выбор по задаче

- Нужен процесс работы ИИ-агента: Agent Skills.
- Нужна память между сессиями: Mem0.
- Нужно понимание большой кодовой базы через MCP: Codebase Memory MCP.
- Нужно уменьшить LLM-контекст: Headroom; для серверного KV-кэша — LMCache.
- Нужен локальный LLM на устройстве: LiteRT-LM.
- Нужно много внешних OAuth/API-интеграций: Nango.
- Нужен публичный источник данных: Public APIs.
- Нужно превратить сайты в Markdown/RAG-данные: Crawl4AI.
- Нужна работа с офисными файлами: OfficeCLI.
- Нужны архитектурные диаграммы: Archify.
- Нужен SQL-клиент: DBeaver.
- Нужны P2P-соединения: Iroh.
- Нужна быстрая JS/TS-компиляция: SWC.
- Нужны React-компоненты: UI Watermelon.
- Нужен интерфейс ИИ-чата или агента: AISDK Agents.
- Нужны анимированные shadcn/ui-компоненты: Skiper UI.
- Нужны дизайн-направления и референсы: Refero Styles или Awesome Design Tools.
- Нужен музыкальный или медиапроект: Music Assistant, Spotube или IPTV — с обязательной проверкой условий использования.
